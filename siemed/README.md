# SIEMED Station

Система тьюторского практического занятия по сестринскому делу (АНПОО «СИЭУиП»).
Интерфейс выдержан в стиле [sielom.ru](https://sielom.ru/): шрифт Wix Madefor Display, белая поверхность, жёлтые кнопки-«таблетки».

## Три приложения

| Адрес | Кто |
|---|---|
| порт **9080** `/` | сайт записи студентов (этот порт пробрасывать наружу) |
| порт **8070** `/` | планшет поста (киоск Chrome) |
| порт **8080** `/` | рабочее место: админка и ответственный в одном клиенте |

Модули: каталог занятий, брони, плеер HDMI (mpv), ресивер RTSP, запись FFmpeg, архив ≥ 2 лет, уведомления WebSocket.

На фаерволе DNAT **только 9080**. Порты 8070 и 8080 остаются в сети здания.

## Debian 12

На станции:

```bash
sudo apt-get install -y rsync
cd /path/to/siemed
sudo bash install/install.sh
```

После установки:

- рабочее место: `http://<IP-станции>:8080/` (логин `admin`, пароль в `/etc/siemed/admin.initial`)
- планшет: киоск Chrome на `http://<IP-станции>:8070/`
- запись с телефона: `http://<внешний-IP>:9080` — этот URL кодируйте в печатный QR
- на фаерволе DNAT **только 9080**, не 8070 и не 8080

Ответственный сотрудник открывает тот же адрес `:8080`, что и администратор. Каталог, камеры, сотрудники и удаление архива видны только роли `admin`; просмотр записей и уведомления о завершении занятия — обеим ролям.

Правки сети и NVR: `/etc/siemed/station.env`, затем `systemctl restart siemed-station`.

Камеры ST-SK6502 в PoE-порты ST-NVR-P0505K15. В рабочем месте проверьте RTSP каналов 1–3, кодек **H.264**. На NVR выключите круглосуточную запись на HDD.

Для вывода на телевизор нужен графический сеанс (автологин) и `DISPLAY=:0`, либо настройка `mpv` на нужный HDMI (`SIEMED_MPV_SCREEN`).

## Разработка (Windows)

```text
cd siemed
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
set SIEMED_DATA_DIR=%CD%\var
set SIEMED_PUBLIC_PORT=9080
set SIEMED_LAN_PORT=8080
set SIEMED_TABLET_PORT=8070
.venv\Scripts\python -m app
```

Без FFmpeg/mpv пост работает в режиме наладки: после видео на планшете кнопка «Видео просмотрено».
